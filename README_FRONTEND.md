# FlowiseChatEmbed - Документация фронтенда

## Обзор проекта

FlowiseChatEmbed - это JavaScript библиотека для встраивания чат-бота Flowise на веб-сайты. Проект построен на **SolidJS** и использует **TypeScript** для типобезопасности.

## Структура проекта

### Основные директории

```
src/
├── components/          # Переиспользуемые UI компоненты
├── features/            # Функциональные модули (bubble, full, popup)
├── queries/             # API запросы и взаимодействие с бэкендом
├── utils/               # Вспомогательные утилиты
├── assets/              # Статические ресурсы (CSS, звуки, изображения)
└── types.ts             # Общие типы TypeScript
```

## Компоненты (components/)

### 🎨 Основные компоненты

#### **Bot.tsx**
**Назначение:** Главный компонент чат-бота, управляющий всей логикой чата.

**Функциональность:**
- Управление состоянием сообщений (пользовательских и бота)
- Обработка отправки сообщений через API
- Поддержка потоковой передачи (streaming) ответов
- Управление историей чата и локальным хранилищем
- Обработка загрузки файлов (изображения, аудио, документы)
- Интеграция с аудио-записью (speech-to-text)
- Управление действиями (actions) и workflow
- Обработка обратной связи (feedback) от пользователей

**Ключевые возможности:**
- Поддержка RAG (Retrieval-Augmented Generation)
- Интеграция с агентскими потоками (agent flows)
- Обработка lead capture форм
- Управление сессиями чата

### 💬 Компоненты пузырьков сообщений (bubbles/)

#### **GuestBubble.tsx**
**Назначение:** Отображение сообщений пользователя в чате.

**Функциональность:**
- Рендеринг текстовых сообщений с поддержкой Markdown
- Отображение загруженных файлов (изображения, аудио, документы)
- Форматирование даты и времени сообщения
- Настройка цветов фона и текста
- Поддержка аватара пользователя
- Обработка HTML-контента (опционально)

**Особенности:**
- Автоматическое форматирование ссылок (открываются в новой вкладке)
- Стилизация кода (inline и блоки)
- Адаптивная верстка для мобильных устройств

---

#### **BotBubble.tsx**
**Назначение:** Отображение ответов бота в чате.

**Функциональность:**
- Рендеринг ответов бота с поддержкой Markdown
- Отображение источников документов (source documents)
- Система обратной связи (лайки/дизлайки)
- Копирование сообщений в буфер обмена
- Отображение reasoning агентов (если включено)
- Отображение workflow в виде дерева
- Обработка действий (actions) и кнопок
- Загрузка файлов из ответов бота

**Особенности:**
- Интерактивные элементы (кнопки, ссылки)
- Диалог для детальной обратной связи
- Визуализация workflow процессов

---

#### **LoadingBubble.tsx**
**Назначение:** Индикатор загрузки во время обработки запроса.

**Функциональность:**
- Отображение анимированных точек, показывающих, что бот "печатает"
- Использует компонент TypingBubble для визуализации

---

#### **TypingBubble.tsx**
**Назначение:** Анимация печатания (три анимированные точки).

**Функциональность:**
- Простая CSS-анимация трех точек
- Используется в LoadingBubble

---

#### **StarterPromptBubble.tsx**
**Назначение:** Отображение стартовых подсказок для быстрого начала диалога.

**Функциональность:**
- Кликабельные подсказки для начала разговора
- Настраиваемый размер шрифта
- Обработка клика для отправки подсказки как сообщения

---

#### **FollowUpPromptBubble.tsx**
**Назначение:** Отображение дополнительных подсказок после ответа бота.

**Функциональность:**
- Похож на StarterPromptBubble, но с рамкой
- Используется для предложения следующих вопросов
- Интерактивные подсказки для продолжения диалога

---

#### **LeadCaptureBubble.tsx**
**Назначение:** Форма для сбора контактной информации пользователя (lead capture).

**Функциональность:**
- Форма с полями: имя, email, телефон
- Валидация данных через Zod
- Интеграция с API для сохранения лидов
- Отображение ошибок валидации
- Индикатор успешного сохранения
- Настраиваемые цвета и размеры

---

#### **AgentReasoningBubble.tsx**
**Назначение:** Отображение процесса рассуждения агента (для agent flows).

**Функциональность:**
- Показывает шаги рассуждения агента
- Отображает использованные инструменты
- Показывает артефакты и документы
- Визуализация цепочки агентов

---

#### **SourceBubble.tsx**
**Назначение:** Отображение источников документов, использованных для генерации ответа.

**Функциональность:**
- Список источников с возможностью клика

## Запросы (queries/)

### **sendMessageQuery.ts**
**Назначение:** Все API запросы для взаимодействия с бэкендом.

**Функции:**
- `sendMessageQuery()` - отправка сообщения
- `isStreamAvailableQuery()` - проверка поддержки streaming
- `sendFeedbackQuery()` - отправка обратной связи
- `addLeadQuery()` - сохранение лида
- `createAttachmentWithFormData()` - загрузка файлов
- `getChatbotConfig()` - получение конфигурации
